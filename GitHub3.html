I set up a GitHub Pipeline and created a new workflow. Afterwards, I changed "main.yml" to "deployment.yml". The ".yml" stands for YAML, which is the programming language used for CI/CD pipelines in GitHub.

Inside the workflow, I wrote the name of this pipeline to be shown inside the GitHub GUI. Then, I wrote the commands to make my GitHub action run every time I push to the main branch. The following command spins up our VM and retrieves the repository. After the name command, I added permissions to push to GitHub Pages without issue. The rest of the "jobs" commands generate a GitHub artifact and upload it to GitHub. This then deploys it.
